# Player base

A house water inlet does not need a building of the map. Set down **away from a map building** (in a base you built
yourself), it serves the fixtures plumbed with a pipe wrench **around it**:

- within **12 squares** (sandbox option *Base inlet range*);
- on its own level and up to **3 floors above** it.

Everything else works as in a house: pipe it to a pump. A barrel reaches the network only through a
[barrel fitting](01-getting-started.md#9-barrel-fitting-fill-or-pump) on a pipe, and without a pump a barrel only feeds
drip lines.

Tips:

- Put the inlet in the middle of the base: the range is counted from the inlet.
- Picking up an inlet removes its hidden tanks; set it down again to bring the water back.
