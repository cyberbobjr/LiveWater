# Retirer le mod

Se désabonner en pleine partie laisserait les tuiles de LiveWater et ses réservoirs cachés dans le monde. Retirez-les
d'abord :

1. En **administrateur** sur un serveur (ou le joueur en solo), clic droit n'importe où, **Retirer LiveWater de ce
   monde (admin)**, puis confirmez. C'est définitif.
2. Tuyaux, pompes, arroseurs, arrivées d'eau, raccords de baril et compteurs d'eau des zones chargées disparaissent,
   avec les réservoirs cachés des arrivées d'eau. Les barils raccordés sont débranchés. Éviers, douches et toilettes
   restent raccordés, simplement sans source.
3. Les pièces des zones **non chargées** partent quand leur zone se charge. Le retrait continue après un redémarrage.
   Passez dans les endroits où vous avez construit des réseaux si vous voulez qu'ils soient nettoyés tout de suite.
4. **Sauvegardez**, quittez, puis **désabonnez-vous** de LiveWater (et retirez-le de la liste des mods du serveur).

Rien n'est rendu : les objets disparaîtraient de toute façon avec le mod. Une pièce posée après le retrait est retirée
au pas de 10 minutes suivant.

Sur un serveur, seul un administrateur peut le faire ; le serveur le vérifie (*Seul un administrateur peut faire
cela.*).
